# [Сайт Рязанского кремля](https://kremlevskiy.github.io/rzn-kreml-in "ссылка на github pages")

Сайт о Рязанском кремле на HTML и CSS (вариант 8).

**Автор:** Савёлов Сергей Вадимович

## Что есть на сайте

- 7 страниц: главная (`index.html`) и по странице на каждое здание — колокольня, Успенский, Архангельский и Христорождественский соборы, Дворец Олега, другие постройки
- кликабельная схема кремля со списком обозначений
- Яндекс.Карта с точкой на кремле
- таблицы, списки, ссылки на Википедию и Культура.РФ
- кнопки «Скачать» и «Написать письмо»
- один `style.css` на все страницы

## Запуск

Все файлы держать в одной папке и открыть `index.html`.
